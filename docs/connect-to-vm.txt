Получение ВМ
В проекте модуля вам предстоит решить задачу, требующую вычислений на видеокарте. Для комфортной работы вы получите доступ к виртуальной машине с GPU. Ваша ВМ будет иметь характеристики:
видеокарта NVIDIA Tesla T4 (CUDA драйвера установлены);
операционная система Ubuntu;
4 ядра и 16 GB операционной памяти;
40 GB SSD;
предустановлены: командная строка Bash, Python 3.10, pip, unzip.
Важно

Время жизни виртуальной машины ограничено 8 часами, затем ВМ отключится. У вас есть два запуска ВМ на этот проект. Дисковое пространство ВМ сохранится на 48 часов с момента первого запуска ВМ.
Если код работает, то генерация и обучение на ВМ займут примерно по 30 минут. 
Чтобы эффективно использовать ресурс ВМ: 
До запуска ВМ спланируйте работу над проектом. Обдумайте, что можно выполнить локально. Запланируйте запуски ВМ.
Подготовьте код генерации и обучения. Локально убедитесь, что все функции отрабатывают корректно.
Переходите на ВМ, когда все подготовительные работы сделаны.
Запускайте ВМ только тогда, когда сможете уделить проекту достаточное количество времени.
В этом уроке вы подготовитесь к выполнению проекта: получите доступ к ВМ, подключитесь к ней, настроите окружение и зависимости. 
Как получить доступ к ВМ
Перейдите к заданию и нажмите на кнопку с ракетой.
В течение 5-10 минут вам будут выданы:
IP-адрес ВМ;
Username для подключения (обычно ubuntu);
SSH ключ для подключения. 
2. Сохраните полученный SSH-ключ: 
   1. В корневой папке вашего компьютера создайте директорию .ssh, либо перейдите в неё, если она уже создана. Обычно она расположена по адресу C:/Users/YourUsername/.ssh/ для Windows (YourUsername замените на нужное имя пользователя) и ~/.ssh для MacOS.
   2. Внутри директории создайте файл user_key (с расширением txt  для Windows или без расширения для MacOS) и вставьте в него ключ. 
   Файл с ключом должен выглядеть так, в конце должна быть пустая строка:
Содержимое файла приватного ключа OpenSSH: заголовок -----BEGIN OPENSSH PRIVATE KEY-----, за которым следует несколько строк Base64-кода, и в конце закрывающий заголовок -----END OPENSSH PRIVATE KEY-----. После последней строки ключа — пустая строка.
Важно

Не показывайте ваш приватный ключ никому ни при каких обстоятельствах. 
Проверьте подключение к ВМ по SSH. Запустите команду в терминале:

ssh -i путь/к/ключу ubuntu@ip-адрес 
Эта команда проверит работоспособность подключения. 
Подключение к ВМ
Для работы над проектом нужно подключиться к ВМ через VSCode, используя расширение Remote - SSH. Оно позволяет открывать удалённую папку на любом удалённом компьютере, виртуальной машине или контейнере с работающим SSH-сервером и в полной мере использовать функционал среды разработки VS Code. 
Установка Remote - SSH
Зайдите в VS Code и выберите слева вкладку Extensions.
В поиске введите Remote - SSH.
Нажмите Install. Все остальные необходимые расширения, например, Remote Explorer, установятся автоматически.
Описание изображения — в тексте урока
Готово! Remote - SSH установлен.
Настройка подключения через Remote - SSH
Теперь подключимся к виртуальной машине по SSH, но уже через VS Code:
В VS Code выберите Remote-SSH: Connect to Host... из палитры команд (View → Command Palette). Появится окно:
Описание изображения — в тексте урока
В открывшемся окне введите имя пользователя и ip-адрес виртуальной машины, разделив имя пользователя и адрес символом @. Пример: ubuntu@89.169.177.120. 
VS Code предложит внести информацию о новом ip-адресе в файл с конфигурациями ssh, достаточно согласиться и добавить к сгенерированной конфигурации путь к файлу с паролем, например: IdentityFile .ssh/user_key. 
Общий вид конфигурации:

Host ***.***.***.***
  HostName ***.***.***.***
  IdentityFile .ssh/user_key
  User ubuntu 
Если VS Code не определит автоматически определить, что ваша ВМ работает на Linux, он  предложит выбрать тип вручную. Выберите Linux.
Описание изображения — в тексте урока
Через некоторое время VS Code подключится к SSH-серверу и настроит себя. После подключения вы окажетесь в пустом окне. Вы можете просмотреть строку состояния, чтобы узнать, к какому хосту вы подключены.
